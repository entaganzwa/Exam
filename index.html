🚀 The Project Process

This project follows a rigorous data science workflow to transform raw conflict and geographical data into actionable insights for educational protection.

  1. Data Collection: Aggregated conflict data from UCDP GED and education facility data from Humanitarian OpenStreetMap.
  2. Data Filtering: Isolated Mali-specific conflict events using automated Python scripts.
  3. Spatial Analysis: Calculated distances between schools and conflict epicenters to identify facilities within high-risk zones (1km radius).
  4. Visualization: Developed interactive Leaflet-based maps and D3/Bootstrap dashboards for real-time monitoring.
